Checking this receipt in your browser...

    These checks run here, with no call to the server beyond fetching the file. The page, the key and the receipt all come from this machine, so for a check that does not trust it, use the key in the repository (docs/keys/receipt-signing.pub) with offline_verify.py. The signing key is on the control plane: a signature shows the receipt came from that machine, not that the machine was uncompromised. The public log is served by the same machine; it only catches a rewrite if someone kept an earlier copy, and the repository holds one.
